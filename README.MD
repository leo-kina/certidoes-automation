# 🤖 Automação Web com Python e Selenium

## 📌 Descrição
Este projeto consiste em uma automação web desenvolvida em **Python utilizando Selenium**, com foco na execução de tarefas automatizadas diretamente pelo navegador.

A aplicação foi pensada para ser utilizada via **terminal**, onde todas as **regras, instruções e orientações de uso são exibidas durante a execução do programa**.

---

## 🛠️ Tecnologias Utilizadas
- Python 3
- Selenium
- WebDriver (ChromeDriver ou equivalente)
- Terminal / CLI

---

## ⚙️ Pré-requisitos
Antes de executar o projeto, certifique-se de ter instalado:

- Python 3.x
- Navegador Google Chrome (ou compatível)
- WebDriver correspondente à versão do navegador
- Biblioteca Selenium
